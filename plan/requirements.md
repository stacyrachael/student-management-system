# Student Management System — Requirements Document

## 1. Introduction
The Student Management System (SMS) is designed to help manage student records,
course enrollment, and academic performance in an organized and efficient way.

This project is being developed as a learning tool to apply:
- Object-Oriented Programming
- Database Integration
- Basic System Design Principles

---

## 2. Objectives
- Store and manage student information digitally
- Allow course registration and tracking
- Record and update student grades
- Enable searching and reporting of student data

---

## 3. Functional Requirements

### 3.1 Student Management
- Add new student
- Update student details
- Delete student record
- View all students

### 3.2 Course Management
- Create courses
- Assign students to courses
- View enrolled students per course

### 3.3 Academic Records
- Record grades
- Update grades
- View student performance

### 3.4 Search Features
- Search student by ID
- Filter students by course
- View reports

---

## 4. Non-Functional Requirements
- System must be easy to use (CLI or simple GUI)
- Data must be stored persistently in a database
- System should prevent duplicate student entries
- Queries must execute efficiently

---

## 5. Future Improvements
- Authentication system (Admin login)
- Web-based interface
- Data visualization dashboards
